## 可执行流程与参数

共同前端：RGB 分割 → 掩码向内腐蚀 5 px → 有限深度且 0.1–1.0 m → 按逐帧内参反投影。symmetric 分支继续关闭全局相机 Z-MAD。

默认配置：共同前端 → 不新增过滤 → 4 mm 体素质心采样 → 原 symmetric 配准。

可选平滑配置：共同前端 → CGAL PCA 法向（20 近邻）→ 1 次双边平滑（20 近邻，15°，KNN 支持）→ 检查有限坐标 → 4 mm 体素质心采样 → 原 symmetric 配准。

可选 SOR 配置：共同前端 → Open3D SOR（20 近邻，6 倍标准差）→ 4 mm 体素采样。实验显示它不适合作为当前全量默认。

不加入 ROR、DBSCAN、MLS、填洞或学习模型；不叠加 SOR 与双边平滑，不更改原始分割轮廓和渲染深度。后半程仍使用原始深度评分，这是本次只改点云预处理的明确范围，不代表已解决所有深度噪声影响。

输入极少或所有坐标重合时不进行无意义的邻域估计，之后仍执行原有最小点数检查。清理后少于要求的点数仍返回失败；不会通过放宽 200 点门槛掩盖过滤问题。

单帧使用示例：
```bash
conda activate embodiedvg
python -m pip install -r requirements-preprocessing.txt
python infer_6d_single.py \
  --rgb <RGB路径> --d2rgb <D2RGB路径> \
  --camera-config <对应相机内参.yaml> --camera-only \
  --output-dir <新的输出目录> \
  --point-filter bilateral --bilateral-neighbors 20 \
  --bilateral-sharpness-angle 15 --voxel-size 0.004
```
去掉 --camera-only 并提供 --robot-pose，可继续使用已有手眼变换。infer_6d_batch.py 支持相同预处理选项；批量共享相机参数的原有约束不变。回退使用 --point-filter none，无需修改源码。

逐帧 JSON 的 input 记录配置；visible_point_cloud.point_filter 记录实现、输入输出点数、SOR 删除数或双边位移均值/最大值。原掩码和原始深度文件不被覆盖。

复现全量重复验证：
```bash
python tools/run_camera_baseline.py \
  --dataset test_data/plug_camera_eval_20261106 \
  --output-dir output/<新的实验名称> \
  --device 0 --warmup-frames 3 --repeats 3 --seed 7 \
  --point-filter bilateral
```
