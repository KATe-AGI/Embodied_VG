# 校准专用点云配准：最终接入与验收

新方法已接入单帧和批量校准入口，使用 `--registration-method calibration`；默认仍为 `symmetric`。夹爪中心参数为 `--clamp-center-end X Y Z`，默认法兰 Link_6 系 `[0,0,0.420]` 米。抓取入口、共享提点/分割/配准算法未修改。

## 实测结果

在 embodiedvg、NVIDIA GeForce RTX 5060 Ti 上，两方案分别预热五帧，再交替运行20轮完整五帧批次，每方案100帧全部成功。计时使用CUDA同步，核心包含分割、观测处理、配准及输出坐标变换；模型/CAD加载、文件读写与复核输出不计入核心。

|方法|核心 P50 ms|核心 P95 ms|成功/总帧数|
|---|---:|---:|---:|
|symmetric|234.04|255.86|100/100|
|calibration|206.80|270.94|100/100|

新/旧 P50 比值 0.8836，P95 比值 1.0589；两者均≤1.20，性能通过。

五帧与用户已确认的第三阶段位姿一致，最大矩阵差小于4.9e-9（JSON舍入）；100次新方法输出完全一致。独立单帧入口与批量入口输出位姿、三点及基座坐标一致。52项测试通过。

## 三次性能改进记录

|版本|改动|P50 比值|P95 比值|结论|
|---|---|---:|---:|---|
|0|初版入口、模型与CAD缓存、同步计时|2.547|3.063|未通过|
|1|缓存端部计算，省去重复校验/支持点掩膜，表面查询4线程|2.287|2.675|未通过|
|2|4线程并行候选；完善提点/语义点计时并统一CAD加载缓存|4.990|6.871|未通过|
|3|4个常驻spawn CPU进程；每进程缓存CAD并限制内部线程数，保留8候选与原排序|0.884|1.059|通过|

第3次改进通过后冻结，不再调整目标函数、候选数、点数或先验。常驻进程仅并行计算原候选，不读取真值、不调用抓取算法生成初值或回退。单帧CLI退出时发现并修复了工作进程清理提示，修复仅在退出路径，未改变核心推理；已重新运行单帧CLI并检查正常退出。

初始化成本：最后基准中新方法首次模型/CAD及进程初始化约2.82秒；另一次独立冷启动单帧实测总计4.40秒，加载约3.09秒。上述207/271ms对应预热后的核心耗时，不能作为冷启动总延迟。复核文件写入不计入核心，五帧保存复核的集成运行有逐帧 `other_review_io_s` 记录。代价是新增4个常驻CPU工作进程；此轮无CPU资源上限要求。

## 输出和边界

JSON仍包含 `t_camera_grasp`、相机/基座位姿、三语义点及复核产物；`grasp_center` 仍距CAD头部90mm，不等同输入夹爪中心。`registration_quality` 附加粗配准/ICP诊断、夹爪中心及辅助roll精度未验证标记。失败不回退旧方法。

新方法的预处理、8候选粗配准、20轮上限点到面ICP及先验采用已验证固定设置；旧方法的ICP阈值/迭代数等调参项不改变这套校准求解器。GPU只负责分割，CAD配准使用CPU进程。若作为Python库长期调用 `run`，结束时调用 `shutdown_calibration_workers()`；两个CLI及基准工具已自动清理。

## 使用与复现

```bash
conda run -n embodiedvg python calibration_6d_batch.py \
  --input-dir test_gt_20260902 \
  --robot-pose -0.014293 0.460711 0.742759 2.167158 0.044541 -3.126827 \
  --registration-method calibration --clamp-center-end 0 0 0.420 \
  --output-dir output/calibration_endpoint_icp_run --save-review --save-ply

conda run -n embodiedvg python tools/benchmark_calibration_entrypoints.py \
  --output output/calibration_endpoint_icp_benchmark_repeat

conda run -n embodiedvg python -m pytest tests -q
```

单帧使用 `calibration_6d_single.py`，将 `--input-dir` 替换为 `--rgb` 与 `--d2rgb`。结果入口为 `output/calibration_endpoint_icp/index.html`；完整逐轮计时、准确性参考CSV、校验记录和代码快照在 `stage4/revision_3/`。前3轮失败基准及前阶段结果均保留。
