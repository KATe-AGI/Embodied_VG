# 插头入槽视觉检验设计讨论

状态：已根据 2026-10-23 用户确认的头部固定、尾部允许摆动语义，将判据改为圆台内长度比例。当前验证见 [圆台验证报告](groove-frustum-validation.md)；此前六帧结果保留为 [历史记录](groove-placement-validation.md)。

## 已确认

- 新增独立脚本，使用 `ultralytics/runs/segment/plug_yolo26n_seg_20261019` 的分割权重。
- 使用 RGB 和对齐深度提取局部点云，配准获得插头轴线，再转换到机器人基座系。
- 目标是检验放置后的几何位置：横向位置、倾斜、沿轴位置；绕长轴 roll 等价。
- 插头头部朝上、尾部朝下是已知先验，无须识别头尾颠倒。
- 正确入槽轴经过 `P_reference + groove_plane_normal_offset_m * n_base`，当前偏移为 0.055 m。这是用户确认的实物关系。
- `axis_offset_m=0.200` 和 `surface_offset_m=0.020` 属于进入装置前的预设位置，不参与本脚本的入槽目标构造。
- 入槽轴方向为基座向上单位向量在装置法向正交平面上的投影并归一化：`u = normalize(z - dot(z,n)*n)`，其中 `z=[0,0,1]`。
- 轴向允许范围为 `C + tail_base_z_offset_m*u` 到 `C + head_base_z_offset_m*u`，其中 `C` 为入槽轴基准点。当前跨度 172 mm 比 CAD 长度 167.8 mm 多出 4.2 mm，是用户有意设置的轴向活动余量，不是待修正的尺寸错误。
- 预测头尾端面中心应落在允许范围附近，不要求分别重合其上下界。现有 AprilTag 预设点计算继续使用原先的固定基座 Z 定义；本讨论的投影方向属于新脚本的入槽检查定义。
- 配准位置和倾斜由观测独立估计；可使用头上尾下先验排除反向候选，不能用目标入槽位置把结果拉回凹槽。
- 允许读取 AprilTag 脚本保存的基座系参考点和法向量。不同拍摄时刻应各自使用对应法兰位姿，装置相对基座须保持固定。
- 最新接口要求：检查帧法兰位姿通过必填的 `--robot-pose` 显式传入，不从 AprilTag JSON 自动复用。示例填写 AprilTag 脚本示例位姿；验证数据目录为 `插头放置判断`，其中有 `true` 和 `false` 子目录。
- 检验结论分为正确入槽、未正确入槽、无法判断。几何通过不代表确认物理接触或支撑力。
- 当前允许区域为以入槽轴段为中轴的有限圆台：上端（头部方向）半径 5 mm，下端（尾部方向）半径 20 mm，半径沿高度线性变化。按用户明确选择，所有横向方向均放宽，采用圆形截面。
- 用户明确要求有限预测长轴至少 80% 的长度在圆台内才判为正确入槽；超出 20% 则判为未正确入槽。不是“超出 80% 才失败”。
- 分母为头尾端面中心间完整三维轴长。上下端面外的部分计为在外，不先裁剪分母；边界计为在内。对轴线与侧面及端面的交点作解析计算，不依赖离散采样密度。80% 边界通过。
- 圆台上下端面沿用已有 −90～+82 mm 范围，不增加旧判据的圆头缓冲区。预测头尾不要求分别与上下界重合，不新增头部单独位置门；最终结论按用户指定的长度比例判定。
- 旧版 5 mm 最大端点距离不再参与放置判定；头尾距离和最大距离保留用于诊断。
- 用户明确不增加配准稳定性检查：每帧只执行一次配准流程，不对子集重复配准，不增加相应阈值。
- 无目标、目标实例歧义、深度或点数不足、参考几何无效、配准失败或没有有限轴线解时输出无法判断。保存配准质量指标用于复核，不将现有配准的 `ok` 当作精度保证；不声称能自动识别所有有限但错误或欠约束的估计。

## 实现交付范围

- 独立单帧入口为 `infer_groove_placement_single.py`，保存结果及 RGB/三维复核产物，使用六帧带标签样例检查行为。
- 输入为 RGB、对齐的原始深度、AprilTag 结果 JSON 和法兰位姿；默认使用凹槽插头分割权重、现有 CAD、相机内参、手眼标定及放置配置。
- 输出三态结论、圆台尺寸、轴线在内/在外长度比例、完整轴长、在内长度、在内参数区间、头尾距离和最大距离（诊断）、预测与允许轴段、坐标变换及配准质量，并提供 RGB 和三维复核。图中显示蓝色圆台、绿色在内轴线和红色在外轴线。
- 采用用户确认的第一帧 `output/apriltag_pose/20261023_163823_957_color_apriltag_pose.json` 为固定参考，保留默认相机及手眼设置。对 `test_data/插头放置判断数据` 两正两负各运行一次，检查实际输出，不根据标签继续调半径和比例阈值。

## 测试边界

- 允许轴段和放置判据的公开几何接口：检查 55 mm 法向偏移、投影向上方向、轴向活动余量、圆台侧面和上下端面、80% 边界、倾斜、线段穿越、刚体坐标变换不变性及无效几何的拒绝。以独立均匀长度测量核对解析结果。该边界不证明图像配准精度。
- 单帧运行入口：检查缺失输入的三态 JSON 和复核产物。真实分割和配准通过六帧本地资产运行验证，不模拟内部配准结果。
- 以上边界来自用户已确认的几何判据、失败语义和输入输出范围；用户“开始实现”的授权覆盖这些必要验证。
